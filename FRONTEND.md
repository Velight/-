
# Frontend (ветка frontend-integration)

Два экрана из макетов: список клиентов и интерактивная карта. Фронтенд отдаётся FastAPI на `/`, статические файлы на `/ui-assets`. Отдельный Node-сервер и сборка не нужны.

## Запуск локально

Из корня репозитория, Python 3.12:

```sh
pip install -r requirements.txt
export API_KEYS_JSON='{"local-demo":{"role":"editor","user_id":"demo","clients":["*"]}}'
export SEED_DEMO=true
uvicorn app.main:create_app --factory --host 127.0.0.1 --port 8000
```

Открыть http://127.0.0.1:8000/ и ввести `local-demo` (только локальный пример; в публичном окружении используйте индивидуальный секрет). При наличии существующего ключа используйте его. API-ключ не включается в исходный код страницы, хранится в sessionStorage текущей вкладки. Модель ассистента определяется настройками сервера; без LLM используется предусмотренный бэкендом режим.

## Поведение

- Клиенты, количество контактов, обновления и охват ЛПР берутся из API, а не из изображения.
- Карта строится из nodes/edges API; кольца соответствуют relationship, предложенные связи пунктирные. Исторический снимок только для чтения, ассистент только для актуальной версии.
- Фильтры и переключение клиент/сделка/человек передаются на сервер; контакт, источник и взаимодействия доступны из боковой панели. Правка контакта/рассмотрение связи используют optimistic version.
- Навигационные иконки и аватар перенесены как векторные контуры из SVG; логотипы — растровые вырезки из предоставленного визуального референса. Текст в исходных SVG переведён в кривые, файл шрифта не предоставлен: используется Mulish при наличии, иначе системный fallback.
- Никаких фиктивных связей или чисел из макета не добавлено в демонстрационную базу.
